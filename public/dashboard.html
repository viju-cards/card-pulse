🧩 Browser Extension einrichten

So installierst du die CardPulse Extension und verbindest sie mit deinem Konto:

1
Öffne den Chrome Web Store und suche nach CardPulse – oder klicke direkt auf den Installationslink.
2
Installiere die Extension und klicke auf das CardPulse-Icon in deiner Browserleiste.
3
Du bist bereits eingeloggt – dein Token wird automatisch an die Extension weitergegeben. Öffne einfach eine Karte auf Cardmarket.
